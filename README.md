# Krave

A modern Instagram clone with AI-driven interactions, built with React and Vite.

## Features
- **AI Discovery**: Swipe to match with AI personas.
- **Activity Feed**: Real-time notifications and matches.
- **Aura Mode**: Immersive visual experience.
- **Apple-like UI**: Smooth animations and glassmorphism.

## Getting Started

1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm run dev`.
